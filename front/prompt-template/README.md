# Настройка промпта

## Назначение и маршрут

- **Раздел меню:** Настройки → **Настройка промпта**.
- **Маршрут (пример):** `/settings/prompt-template`.

## Макет (wireframe)

```text
+------------------------------------------------------------------+
|  Заголовок «Настройка промпта»                                    |
+------------------------------------------------------------------+
|  Многострочное поле шаблона: резиновая ширина, вертикальный       |
|  resize, высота заполняет контентную область страницы             |
+------------------------------------------------------------------+
|  Дата последнего обновления (read-only): updatedAt, иначе createdAt|
+------------------------------------------------------------------+
|  [ Кнопка «Сохранить» ]                                           |
+------------------------------------------------------------------+
```

## Данные и API

Базовый URL: `VITE_SETTINGS_MANAGER_BASE_URL`. Контракт: [services/settings-manager/openapi.yaml](../../services/settings-manager/openapi.yaml).

### Загрузка при открытии

- **Метод:** `GET /prompt-template`
- **200:** тело `PromptTemplate`: `template` (nullable), `createdAt`, `updatedAt` (nullable)
- **404:** в таблице нет строки — показать ошибку или пустое состояние по UX
- **500:** сообщение пользователю

### Сохранение

- **Метод:** `POST /prompt-template`
- **Content-Type:** `text/plain`, тело — текст шаблона
- **200:** тело `PromptTemplate` — обновить поле ввода при необходимости и блок дат из ответа

## Алгоритмы активных элементов

### Многострочное поле ввода

- Свободный текст; плейсхолдеры `${JOB_POSTING_CONTENT}` и `${RESUME}` документированы в [prompt-template.md](../../services/settings-manager/prompt-template.md).

### Кнопка «Сохранить»

- Отправить `POST /prompt-template` с телом `text/plain`.
- Индикатор загрузки на время запроса.
- Успех: обновить даты из JSON.

### Read-only дата

- Показать **`updatedAt`**, если заполнено; иначе **`createdAt`**.

## Открытие страницы (mount)

1. Выполнить `GET /prompt-template`.
2. При **200** — заполнить поле и дату.

# orchestration-scheduler REST API

Работает с PostgresSQL:

- База данных `joposcragent`
- Схема `orchestration`
- Таблица `scheduler`

## Чтение настроек шедулера

`GET /settings`

Алгоритм работы:

1. Выбирает первую строку из таблицы `scheduler`
2. Возвращает значения полей `next_run` и `cron_expression`
3. Если строки нет, возвращает `null` для обоих полей
4. При любом не перехваченном исключении возвращает HTTP 500 с текстом ошибки

## Обновление расписания запуска

`PUT /settings/cron-expression`

|Входящий параметр|Источник|Описание|
|---|---|---|
|📌`{UpdateCronExpression}`|тело запроса|расписание в формате crontab|

Алгоритм работы:

1. Записывает в колонку `cron_expression` первой строки таблицы `scheduler` значение `{UpdateCronExpression}.value`
2. Если строки нет - создает ее
3. При любом не перехваченном исключении возвращает HTTP 500 с текстом ошибки

## Принудительная установка даты следующего запуска

`PUT /settings/next-run`

|Входящий параметр|Источник|Описание|
|---|---|---|
|📌`{UpdateNextRun}`|тело запроса|дата и время следующего запуска с часовым поиском|

Алгоритм работы:

1. Записывает в колонку `next_run` первой строки таблицы `scheduler` значение `{UpdateNextRun}.value`
2. Если строки нет - создает ее
3. При любом не перехваченном исключении возвращает HTTP 500 с текстом ошибки
